# HTML Concepts Hub 🌐

A structured repository for learning **HTML from basics to advanced concepts** with clean examples, organized folders, and beginner-friendly notes.

## 📂 Repository Structure

* `basic-structure/` – HTML boilerplate and page structure
* `text-formatting/` – headings, paragraphs, formatting tags
* `containers/` – div, span and layout containers
* `links-media/` – links, images, audio, video
* `html-lists/` – ordered, unordered, description lists
* `html-tables/` – tables, rows, columns, colspan, rowspan
* `form/` – forms and important input types
* `semantic/` – semantic HTML5 tags
* `entities/` – HTML entities examples
* `code-meaning/` – code tags and meaning tags
* `docs/` – notes and learning resources

## 🎯 What You’ll Learn

✅ HTML fundamentals
✅ Semantic HTML5 structure
✅ Forms and input fields
✅ Tables, lists, and media
✅ Best practices for webpage structure
✅ Frontend interview preparation topics

## 🛠 How to Run Code

1. Open any `.html` file in browser
2. Or use VS Code + Live Server extension
3. Edit files and see live changes instantly

## 🌟 Best For

* Beginners learning HTML
* Students building portfolio projects
* Frontend learners before CSS & React
* Anyone revising HTML quickly
