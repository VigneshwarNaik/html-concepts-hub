# Difference Between `<b>` and `<strong>`

Both tags make text **bold** on the screen.

## Difference

- `<b>` → Only makes text bold
- `<strong>` → Makes text bold and indicates important text

---

## Example

```html
<b>Vignesh</b>
```

### Output
**Vignesh**

Meaning:
- Just bold text

---

```html
<strong>Warning!</strong>
```

### Output
**Warning!**

Meaning:
- Important warning message

---

## Interview Answer

> `<b>` tag is used only for bold text styling, whereas `<strong>` tag is used for important text. Both appear bold, but `<strong>` gives semantic meaning that the content is important.

# Difference Between `<i>` and `<em>`

Both tags usually display text in *italic* style.

## Difference

- `<i>` → Only makes text italic
- `<em>` → Emphasizes important text

---

## Example

```html
<p>This is <i>italic</i> text.</p>

<p>This is <em>important</em> text.</p>
```

### Output

This is *italic* text.

This is *important* text.

---

## Interview Answer

> `<i>` tag is used only for italic styling, whereas `<em>` tag is used to emphasize text. Both appear italic, but `<em>` gives semantic meaning and importance.
